# Circular Motion Analysis — Master Orchestrator

You are the master orchestrator for a circular motion video analysis pipeline.
Run Steps 1 through 6 sequentially, spawn three subagents in parallel, then compile the final LaTeX report and summary. Steps 1–5 are agentic perception (scene, tracking, validation, center bootstrap, reference sizing); Step 6 runs the FROZEN, deterministic `analysis/` pipeline that owns all kinematics and writes `stats.json`.

Tools available: Python, ffmpeg/ffprobe, HTTP tracking API (remote), pdflatex.

**Object tracking is performed EXCLUSIVELY by calling the remote HTTP API via `requests.post()`. You must NEVER install, import, or run SAM2, SAM3, segment-anything, or any tracking/segmentation model locally. The tracking server is already running on a separate GPU machine. Your only interface to it is `POST {TRACKING_API_URL}/track`.**

## HARD RULES

- **NEVER run SAM2, SAM3, or any segmentation/tracking model locally.**
  No `pip install sam2`, no `from sam2 import`, no `SamPredictor`, no `build_sam2_video_predictor`, no local model loading. ALL tracking is done by sending HTTP requests to the remote tracking API. If you find yourself writing `import sam2` or similar — STOP, you are violating this rule.
- **Tracking = HTTP POST to `{TRACKING_API_URL}/track` via `requests`.**
  The only Python packages needed for tracking are `requests` and `json`.
- **The pipeline makes 1 successful tracking API call** (Step 2, on the original video), with **bounded retries ONLY when the tracking coverage quality-gate fails** (SAM3 is non-deterministic — see Step 2.1). If `api_cache.json` already exists, the API is not called at all (cache HIT). Cropped-video-space trajectories are produced by subtracting the crop offset — NOT by calling the API again. Do NOT add `requests.post(…/track…)` anywhere outside the gated retry loop in Step 2.1; downstream steps must never re-call the tracker.
- Work only in the current directory. No `/tmp`, home dirs, or absolute paths outside the workspace.
- Never fabricate measurements. All reported numbers must come from code.
- Missing detections → `NaN`. Never repeat last known coordinates.
- Exclude idle intervals from all summary statistics.
- If results are implausible, diagnose and rerun — never accept bad results.
- Never distort aspect ratio. Always read `sample_aspect_ratio` and `display_aspect_ratio` from ffprobe before any geometric computation.
- ffprobe is the sole source of truth for FPS and aspect ratios.
- Pass only file paths to subagents for large data (video, CSV, cache). Inject the stats dict values directly as context — not as a file path.
- Step execution order is strict: 1 → 2 → 3 → 4 → 5 → 6.
- **Kinematics is FROZEN. Never reimplement, edit, or "improve" anything under `analysis/`.** That seeded package (old steps 5–8: cleaning, RANSAC, calibration, active detection, kinematics, phases, stats.json) is the single source of truth. Your job ends at writing `pipeline_inputs.json`; Step 6 just runs `python -m analysis.run`. Do NOT author your own kinematics, period, or stats.json code — that non-determinism is exactly what this design removes.
- **All pixel coordinates throughout the pipeline are in cropped-video space**, with ONE exception: the `pipeline_inputs.json` contract (Step 5) carries the trajectory and center in **full-frame (display) space** with `coordinate_space: "display"`, and the FROZEN contract subtracts the crop offset deterministically. Do NOT crop-subtract the contract trajectory/center by hand — that hand-transform is exactly what made `stats.json` non-deterministic (one run subtracted the offset, one didn't). Never remap cropped coordinates back to original frame coordinates anywhere else; the crop offset is stored once in `stats.json` and `roi_crop_meta.json` for external reference only.
- **Do NOT write a single monolithic script.** Break all code into modules corresponding to the steps.

```python
_LOG_PATH = "analysis_output/debug/pipeline.log"

def log(msg: str) -> None:
    ts = time.strftime("%H:%M:%S")
    line = f"[{ts}] {msg}"
    print(line, flush=True)
    with open(_LOG_PATH, "a") as _lf:
        _lf.write(line + "\n")

# ── Validation flags ───────────────────────────────────────────────────────
_validation_flags: list[str] = []

def set_validation_flag(flag: str) -> None:
    if flag not in _validation_flags:
        _validation_flags.append(flag)
        log(f"[FLAG] {flag}")

# ── Wall-clock timing ──────────────────────────────────────────────────────
_step_times: dict[str, float] = {}

def step_start(name: str) -> float:
    t = time.time()
    _step_times[name] = t
    log(f"[STEP START] {name}")
    return t

def step_end(name: str) -> float:
    elapsed = time.time() - _step_times.get(name, time.time())
    log(f"[STEP END] {name} — {elapsed:.1f}s")
    return elapsed

# ── ffprobe helper ─────────────────────────────────────────────────────────
def ffprobe_video(path: str) -> dict:
    """Return stream dict for first video stream via ffprobe. Raises on failure."""
    r = subprocess.run([
        "ffprobe", "-v", "error",
        "-select_streams", "v:0",
        "-show_entries",
        "stream=width,height,nb_frames,r_frame_rate,sample_aspect_ratio,display_aspect_ratio,codec_name",
        "-show_entries", "format=duration",
        "-of", "json", path
    ], capture_output=True, text=True)
    if r.returncode != 0:
        raise RuntimeError(f"[ABORT] ffprobe failed on {path}:\n{r.stderr}")
    data = json.loads(r.stdout)
    streams = data.get("streams", [])
    if not streams:
        raise RuntimeError(f"[ABORT] ffprobe found no video streams in {path}")
    s = streams[0]
    s["_format"] = data.get("format", {})
    return s

# ── Minimum file size guard ────────────────────────────────────────────────
def assert_file_exists(path: str, min_bytes: int = 1000, label: str = "") -> None:
    tag = f" [{label}]" if label else ""
    if not os.path.exists(path):
        raise RuntimeError(f"[ABORT]{tag} Expected file does not exist: {path}")
    size = os.path.getsize(path)
    if size < min_bytes:
        raise RuntimeError(f"[ABORT]{tag} File too small ({size} < {min_bytes} bytes): {path}")
    log(f"[OK]{tag} {path} ({size:,} bytes)")
```

### Step 2 — ROI Detection & Crop (1 API Call, Cached)

> **Purpose:** Crop the video to the region of interest before sending to the tracking API. A tight, object-centred crop eliminates background clutter that degrades SAM 2 mask propagation. All pixel coordinates downstream are in **cropped-video space**.
>
> **This step makes AT MOST 1 HTTP API call. If `api_cache.json` exists from a previous run, the API is NOT called at all (cache HIT).**
> Crop-space trajectories are produced by subtracting the crop offset from full-frame coordinates — NOT by calling the API again.
>
> **Tracking is done by the remote server via `requests.post()`. Do NOT import or run any tracking model locally.**

**2.1 — Load Cache or Call API (exactly once, ever)**

```python
import requests

step_start("step2")

CACHE_PATH = "analysis_output/data/api_cache.json"
targets_json = json.dumps([tracked_label, ref_label])

if os.path.exists(CACHE_PATH):
    log("[API] Cache HIT — loading from api_cache.json (no API call)")
    with open(CACHE_PATH) as f:
        cache = json.load(f)
    trajectories_full = cache["trajectories"]
    video_info        = cache["video_info"]
else:
    # SAM3 tracking is NON-DETERMINISTIC: the same video can return a clean full-coverage
    # track on one call and a degraded partial one (e.g. 60% coverage, wrong radius) on the
    # next. Computing kinematics from a degraded track yields confident-but-wrong numbers.
    # So we GATE on coverage of the tracked object and retry, keeping the best attempt.
    # This is the ONE exception to the single-API-call rule — retries fire ONLY when a
    # quality check fails, never speculatively.
    MAX_TRACK_ATTEMPTS  = 3
    MIN_TRACK_COVERAGE  = 0.85   # accept immediately at/above this
    HARD_FLOOR_COVERAGE = 0.50   # best attempt below this → ABORT (don't fabricate physics)
    api_timeout = max(600, int(duration_s * 18))
    log(f"[API] Cache MISS — calling tracking API (timeout={api_timeout}s)")

    def _track_once():
        with open(VIDEO_PATH, "rb") as vf:
            r = requests.post(
                f"{TRACKING_API_URL}/track",
                files={"file": ("input.mp4", vf, "video/mp4")},
                data={"targets": targets_json},
                timeout=api_timeout,
            )
        if r.status_code != 200:
            raise RuntimeError(f"[ABORT] API returned {r.status_code}: {r.text[:500]}")
        res = r.json()
        if res.get("status") != "success":
            raise RuntimeError(f"[ABORT] API tracking failed: {res}")
        miss = [l for l in [tracked_label, ref_label] if l not in res.get("trajectories", {})]
        if miss:
            raise RuntimeError(f"[ABORT] API response missing trajectories for: {miss}. Available keys: {list(res.get('trajectories', {}).keys())}")
        return res

    def _coverage(res):
        nbf  = (res.get("video_info") or {}).get("nb_frames") or 0
        dets = res.get("trajectories", {}).get(tracked_label, [])
        valid = len([d for d in dets if d.get("cx") is not None])
        return (valid / nbf if nbf else 0.0), valid, nbf

    def _reset_sam3():
        # SAM3 coverage decays over the server's lifetime, so recycle it before
        # retrying. POST /reset exits the server; its supervisor relaunches a fresh
        # one. Wait for /health, then the next attempt runs against a clean server.
        try:
            requests.post(f"{TRACKING_API_URL}/reset", timeout=10)
        except Exception:
            pass
        for _ in range(30):
            time.sleep(1)
            try:
                if requests.get(f"{TRACKING_API_URL}/health", timeout=3).status_code == 200:
                    return True
            except Exception:
                pass
        return False

    best_result, best_cov = None, -1.0
    for attempt in range(1, MAX_TRACK_ATTEMPTS + 1):
        result = _track_once()
        cov, valid, nbf = _coverage(result)
        log(f"[API] attempt {attempt}/{MAX_TRACK_ATTEMPTS}: '{tracked_label}' coverage={cov:.2f} ({valid}/{nbf})")
        if cov > best_cov:
            best_result, best_cov = result, cov
        if cov >= MIN_TRACK_COVERAGE:
            break
        if attempt < MAX_TRACK_ATTEMPTS:
            log(f"[API] coverage {cov:.2f} < {MIN_TRACK_COVERAGE} — recycling SAM3 and retrying.")
            log("[API] SAM3 recycled (fresh server up)." if _reset_sam3()
                else "[API] SAM3 reset/health-check timed out; retrying anyway.")

    if best_cov < HARD_FLOOR_COVERAGE:
        raise RuntimeError(
            f"[ABORT] Tracking coverage {best_cov:.2f} below hard floor {HARD_FLOOR_COVERAGE} "
            f"after {MAX_TRACK_ATTEMPTS} attempts — refusing to compute kinematics from a degraded track.")
    if best_cov < MIN_TRACK_COVERAGE:
        set_validation_flag("tracking_coverage_below_target")
        log(f"[API] Proceeding with best available coverage={best_cov:.2f} (flagged).")

    api_result        = best_result
    trajectories_full = api_result["trajectories"]
    video_info        = api_result["video_info"]

    with open(CACHE_PATH, "w") as f:
        json.dump({
            "video_file":     os.path.basename(VIDEO_PATH),
            "trajectories":   trajectories_full,
            "video_info":     video_info,
            "track_coverage": best_cov,
        }, f)
    log(f"[API] Cache saved → {CACHE_PATH} (coverage={best_cov:.2f})")

# ── CRITICAL: Handle Auto-Rotation from FFmpeg ────────────────────────────
# The API returns the raw codec dimensions in `video_info`.
# However, ffmpeg (and our tracker) auto-rotates the decoded frames based on metadata.
# If the rotation is ±90 or ±270, the display dimensions are swapped.
# All tracking coordinates are natively in this display space.
rotation = video_info.get("rotation", 0)
if abs(rotation) in (90, 270):
    FRAME_W = video_info["height"]
    FRAME_H = video_info["width"]
    log(f"[API] Video has {rotation}° rotation. Swapped dimensions to display space: {FRAME_W}x{FRAME_H}")
else:
    FRAME_W = video_info["width"]
    FRAME_H = video_info["height"]

NB_FRAMES = video_info["nb_frames"]
FPS       = video_info["fps"]

# FPS reconciliation — ffprobe is authoritative
if abs(FPS - ffprobe_fps) / ffprobe_fps > 0.01:
    log(f"[API] FPS mismatch: API={FPS:.3f}, ffprobe={ffprobe_fps:.3f}. Using ffprobe.")
    FPS = ffprobe_fps

# Detection counts
for lbl in [tracked_label, ref_label]:
    n = len([d for d in trajectories_full.get(lbl, []) if d.get("cx") is not None])
    log(f"[API] '{lbl}' valid detections: {n} / {NB_FRAMES}")
```

**2.2 — Compute Orbit-Aware Crop Box**

```python
def compute_crop_box(trajectories, tracked_label, ref_label, fw, fh, pad=1.3):
    """
    Compute a padded bounding box that covers all detections of both labels.
    Returns (x_off, y_off, crop_w, crop_h) with even dimensions (libx264 req).
    """
    all_bboxes = []
    for label in [tracked_label, ref_label]:
        for det in trajectories.get(label, []):
            if det.get("bbox"):
                all_bboxes.append(det["bbox"])

    if not all_bboxes:
        log("[ROI] No bboxes found — returning full frame.")
        return (0, 0, fw, fh)

    bboxes = np.array(all_bboxes, dtype=float)
    env_x0, env_y0 = bboxes[:, 0].min(), bboxes[:, 1].min()
    env_x1, env_y1 = bboxes[:, 2].max(), bboxes[:, 3].max()
    env_cx = (env_x0 + env_x1) / 2
    env_cy = (env_y0 + env_y1) / 2

    crop_w = int(min((env_x1 - env_x0) * pad, fw))
    crop_h = int(min((env_y1 - env_y0) * pad, fh))

    crop_w = crop_w if crop_w % 2 == 0 else crop_w - 1
    crop_h = crop_h if crop_h % 2 == 0 else crop_h - 1

    x_off = int(max(0, min(env_cx - crop_w / 2, fw - crop_w)))
    y_off = int(max(0, min(env_cy - crop_h / 2, fh - crop_h)))

    x_off = max(0, min(x_off, fw - crop_w))
    y_off = max(0, min(y_off, fh - crop_h))

    return (x_off, y_off, crop_w, crop_h)

pad      = 1.3
crop_box = compute_crop_box(trajectories_full, tracked_label, ref_label, FRAME_W, FRAME_H, pad)
```

**2.3 — Crop Validation Loop (math only)**

Validate the crop by transforming full-frame bounding boxes into crop-space. If validation fails, widen and retry.

```python
MAX_ITER           = 3
COVERAGE_THRESHOLD = 0.80   # ≥ 80% of detections must land inside crop
MARGIN_THRESHOLD   = 20     # px — bbox must not clip the crop boundary

for iteration in range(1, MAX_ITER + 1):
    x_off, y_off, crop_w, crop_h = crop_box
    tracked_dets = trajectories_full.get(tracked_label, [])

    total_detections = len(tracked_dets)
    if total_detections == 0:
        log("[ROI] No detections for tracked label — falling back to full frame.")
        crop_box = (0, 0, FRAME_W, FRAME_H)
        set_validation_flag("roi_crop_failed_fallback")
        break

    n_in_crop, margins = 0, []
    for d in tracked_dets:
        bx0, by0, bx1, by1 = d["bbox"]
        cx0, cy0 = bx0 - x_off, by0 - y_off
        cx1, cy1 = bx1 - x_off, by1 - y_off
        ccx = (cx0 + cx1) / 2
        ccy = (cy0 + cy1) / 2
        if 0 <= ccx <= crop_w and 0 <= ccy <= crop_h:
            n_in_crop += 1
            m_left   = cx0 if x_off > 0 else 9999.0
            m_top    = cy0 if y_off > 0 else 9999.0
            m_right  = crop_w - cx1 if x_off + crop_w < FRAME_W else 9999.0
            m_bottom = crop_h - cy1 if y_off + crop_h < FRAME_H else 9999.0
            margins += [m_left, m_top, m_right, m_bottom]

    coverage   = n_in_crop / total_detections
    min_margin = float(np.min(margins)) if margins else 0.0

    log(f"[ROI iter {iteration}] coverage={coverage:.2f}  min_margin={min_margin:.1f}px  crop={crop_box}")

    if coverage >= COVERAGE_THRESHOLD and min_margin >= MARGIN_THRESHOLD:
        log(f"[ROI] Accepted at iteration {iteration}.")
        break

    if coverage < COVERAGE_THRESHOLD:
        log(f"[ROI] Low coverage ({coverage:.2f} < {COVERAGE_THRESHOLD}). Widening by 15%.")
    else:
        log(f"[ROI] Margin too small ({min_margin:.1f}px < {MARGIN_THRESHOLD}px). Widening by 15%.")

    pad *= 1.15
    crop_box = compute_crop_box(trajectories_full, tracked_label, ref_label, FRAME_W, FRAME_H, pad)

    if iteration == MAX_ITER:
        set_validation_flag("roi_crop_failed_fallback")
        log("[ROI] All iterations exhausted — falling back to full frame.")
        crop_box = (0, 0, FRAME_W, FRAME_H)

x_off, y_off, crop_w, crop_h = crop_box
use_full_frame = (crop_box == (0, 0, FRAME_W, FRAME_H))
```

**2.4 — Transform Trajectories & Crop Video**

```python
def transform_to_crop_space(trajectories_full, x_off, y_off):
    cropped = {}
    for label, dets in trajectories_full.items():
        cropped[label] = []
        for d in dets:
            bx0, by0, bx1, by1 = d["bbox"]
            new_det = {
                "frame": d["frame"],
                "cx":    d["cx"] - x_off,
                "cy":    d["cy"] - y_off,
                "bbox":  [bx0 - x_off, by0 - y_off, bx1 - x_off, by1 - y_off],
            }
            if "obox" in d:
                new_det["obox"] = [[p[0] - x_off, p[1] - y_off] for p in d["obox"]]
            cropped[label].append(new_det)
    return cropped

MIN_VIDEO_BYTES = 50_000

if use_full_frame:
    trajectories       = trajectories_full
    final_cropped_path = VIDEO_PATH
    log(f"[ROI] Full-frame path — no ffmpeg crop. Using: {VIDEO_PATH}")
    assert_file_exists(VIDEO_PATH, min_bytes=MIN_VIDEO_BYTES, label="source_video")
else:
    trajectories       = transform_to_crop_space(trajectories_full, x_off, y_off)
    final_cropped_path = "analysis_output/roi/cropped.mp4"

    log(f"[ROI] Cropping {FRAME_W}x{FRAME_H} → {crop_w}x{crop_h} @ offset ({x_off},{y_off})")

    ffmpeg_crop = subprocess.run([
        "ffmpeg", "-y", "-i", VIDEO_PATH,
        "-vf",    f"crop={crop_w}:{crop_h}:{x_off}:{y_off}",
        "-c:v",   "libx264", "-crf", "18", "-preset", "fast",
        final_cropped_path
    ], capture_output=True, text=True)

    if ffmpeg_crop.returncode != 0:
        raise RuntimeError(f"[ABORT] ffmpeg crop failed:\n{ffmpeg_crop.stderr}")

    assert_file_exists(final_cropped_path, min_bytes=MIN_VIDEO_BYTES, label="cropped.mp4")

    crop_stream = ffprobe_video(final_cropped_path)
    actual_w, actual_h = int(crop_stream["width"]), int(crop_stream["height"])

    if actual_w != crop_w or actual_h != crop_h:
        raise RuntimeError(f"[ABORT] Cropped video dimensions mismatch: expected {crop_w}x{crop_h}, got {actual_w}x{actual_h}.")

    actual_nb = int(crop_stream.get("nb_frames", 0))
    if actual_nb < 1:
        raise RuntimeError(f"[ABORT] Cropped video reports 0 frames: {final_cropped_path}")

    log(f"[ROI] Cropped video verified: {actual_w}x{actual_h}, {actual_nb} frames — {final_cropped_path}")
```

### Coordinate Mapping Helpers

```python
def cropped_to_original(cx, cy, crop_meta):
    """Map a point from cropped-video space back to original-frame space."""
    return cx + crop_meta["x_off"], cy + crop_meta["y_off"]

def original_to_cropped(ox, oy, crop_meta):
    """Map a point from original-frame space to cropped-video space."""
    return ox - crop_meta["x_off"], oy - crop_meta["y_off"]
```

### Step 5 — Reference Sizing & Pipeline Input Contract

> **Purpose:** Measure the reference object's pixel size, resolve its real-world
> size, and hand the tracking data to the FROZEN pipeline. You do NOT compute
> kinematics, RANSAC, calibration, period, phases, or stats.json yourself — the
> seeded `analysis/` package owns all of that (old steps 5–8). Re-authoring it is
> what produced 28 different stats.json schemas and invalid `NaN`. Your only job
> here is to produce `pipeline_inputs.json` (the contract in `analysis/contract.py`).

```python
step_start("step5")

# ── Reference object pixel diameter (from its tracked bboxes) ───────────────
width_px_vals, height_px_vals = [], []
for d in trajectories[ref_label]:
    if d.get("bbox"):
        bx0, by0, bx1, by1 = d["bbox"]
        width_px_vals.append(bx1 - bx0)
        height_px_vals.append(by1 - by0)
if not width_px_vals:
    raise RuntimeError(f"[ABORT] No valid bboxes for reference '{ref_label}'.")
width_px_median  = float(np.median(width_px_vals))
height_px_median = float(np.median(height_px_vals))
diameter_px      = (width_px_median + height_px_median) / 2.0
if abs(width_px_median - height_px_median) / diameter_px > 0.15:
    set_validation_flag("bbox_aspect_suspicious")

# ── Real-world size of the reference object ─────────────────────────────────
if physical_size_sidecar is not None:
    physical_size_m, physical_size_source = float(physical_size_sidecar), "sidecar"
else:
    # Fill in a world-knowledge estimate for ref_label (metres).
    physical_size_m, physical_size_source = 0.3000, "world_knowledge"
    set_validation_flag("physical_size_estimated")

# ── Short, human-friendly scene title for artifact titles ───────────────────
# Used as the title on every plot and the report (e.g. "red phone on turntable").
# Condense the raw labels into 2–5 plain words: drop filler ("smartphone with red
# screen" → "red phone", "black circular turntable" → "turntable"), join with "on".
# It is cosmetic only — the frozen contract falls back to "<tracked> on <ref>" if
# omitted, so never block on it.
scene_title = f"{tracked_label} on {ref_label}"   # replace with a cleaner short form

# ── Per-frame tracked-object centroid, FULL-FRAME (display) space ────────────
# CRITICAL: emit the RAW tracker coordinates (full-frame / display space) — use
# `trajectories_full`, NOT the cropped `trajectories`. Do NOT subtract x_off/y_off
# here. The FROZEN contract (analysis/contract.py) subtracts the crop offset from
# BOTH the trajectory and the center together, so they are guaranteed to share one
# space. (Crop-subtracting the trajectory by hand here is what made IMG_3072
# non-deterministic: one run subtracted, one didn't, while the center stayed
# cropped → 87 px mismatch → garbage period / stable_omega.)
tracked_by_frame = {d["frame"]: d for d in trajectories_full[tracked_label]}
def _coord(i, key):
    d = tracked_by_frame.get(i)
    if d is None or d.get(key) is None:
        return None
    v = float(d[key])
    return None if np.isnan(v) else v
traj_x = [_coord(i, "cx") for i in range(NB_FRAMES)]
traj_y = [_coord(i, "cy") for i in range(NB_FRAMES)]

# Center in the SAME full-frame space. cx_calibration/cy_calibration are cropped
# (Step 4 subtracted the offset); add it back so the contract can subtract once,
# uniformly, for trajectory and center alike.
center_cx_full = float(cx_calibration) + float(x_off)
center_cy_full = float(cy_calibration) + float(y_off)

# ── Write the input contract (REQUIRED keys: see analysis/contract.py) ──────
# coordinate_space="display" tells the frozen contract these are full-frame pixels;
# it performs the one, deterministic display→cropped conversion using roi_crop.
pipeline_inputs = {
    "fps": float(FPS),
    "duration_s": float(duration_s),
    "n_raw_frames": int(NB_FRAMES),
    "object_name": object_name,
    "scene_title": scene_title,
    "tracked_label": tracked_label,
    "ref_label": ref_label,
    "coordinate_space": "display",
    "trajectory_x_px": traj_x,
    "trajectory_y_px": traj_y,
    "center": {
        "cx_px": center_cx_full,
        "cy_px": center_cy_full,
        "source": "user_mark" if user_center_used else "bootstrap",
    },
    "reference": {
        "diameter_px": float(diameter_px),
        "physical_size_m": float(physical_size_m),
        "physical_size_source": physical_size_source,
    },
    "roi_crop": {
        "x_off": int(x_off), "y_off": int(y_off),
        "crop_w": int(crop_w), "crop_h": int(crop_h),
        "fallback": bool(use_full_frame),
    },
}
import json as _json
with open("analysis_output/data/pipeline_inputs.json", "w") as f:
    _json.dump(pipeline_inputs, f, indent=2)
log(f"[Step 5] pipeline_inputs.json written: diameter_px={diameter_px:.1f} "
    f"physical_size_m={physical_size_m} source={pipeline_inputs['center']['source']}")
step_end("step5")
```
