# Circular Motion Analysis — Master Orchestrator

You are the master orchestrator for a circular motion video analysis pipeline.
Run Steps 1 through 8 sequentially, spawn three subagents in parallel, then compile the final LaTeX report and summary.

Tools available: Python, ffmpeg/ffprobe, HTTP tracking API (remote), pdflatex.

**Object tracking is performed EXCLUSIVELY by calling the remote HTTP API via `requests.post()`. You must NEVER install, import, or run SAM2, SAM3, segment-anything, or any tracking/segmentation model locally. The tracking server is already running on a separate GPU machine. Your only interface to it is `POST {TRACKING_API_URL}/track`.**

---

## HARD RULES

- **NEVER run SAM2, SAM3, or any segmentation/tracking model locally.**
  No `pip install sam2`, no `from sam2 import`, no `SamPredictor`, no `build_sam2_video_predictor`, no local model loading. ALL tracking is done by sending HTTP requests to the remote tracking API. If you find yourself writing `import sam2` or similar — STOP, you are violating this rule.
- **Tracking = HTTP POST to `{TRACKING_API_URL}/track` via `requests`.**
  The only Python packages needed for tracking are `requests` and `json`.
- **The entire pipeline makes EXACTLY 1 HTTP API call.** That single call happens in Step 2 on the original video. If `api_cache.json` already exists, the API is not called at all (cache HIT). Cropped-video-space trajectories are produced by subtracting the crop offset — NOT by calling the API again. If you are about to write a second `requests.post(…/track…)` — STOP, you are violating this rule.
- Work only in the current directory. No `/tmp`, home dirs, or absolute paths outside the workspace.
- Never fabricate measurements. All reported numbers must come from code.
- Missing detections → `NaN`. Never repeat last known coordinates.
- Exclude idle intervals from all summary statistics.
- If results are implausible, diagnose and rerun — never accept bad results.
- Never distort aspect ratio. Always read `sample_aspect_ratio` and `display_aspect_ratio` from ffprobe before any geometric computation.
- ffprobe is the sole source of truth for FPS and aspect ratios.
- Pass only file paths to subagents for large data (video, CSV, cache). Inject the stats dict values directly as context — not as a file path.
- Step execution order is strict: 1 → 2 → 3 → 4 → 5 → 6 → 7 → 8.
- **All pixel coordinates throughout the pipeline are in cropped-video space.** Never remap back to original frame coordinates. The crop offset is stored once in `stats.json` and `roi_crop_meta.json` for external reference only.
- **Do NOT write a single monolithic script.** Break all code into modules corresponding to the steps.

## PIPELINE BOOTSTRAP

Define these helpers at the very top of your orchestration script before any step runs. Every subsequent step assumes they exist.

```python
import os, sys, json, subprocess, time
import numpy as np

# ── Output directories — create once upfront ──────────────────────────────
DIRS = [
    "analysis_output/frames_1fps",
    "analysis_output/roi",
    "analysis_output/roi/frames_iter1",
    "analysis_output/debug",
    "analysis_output/data",
    "analysis_output/plots",
    "analysis_output/video_annotation/contact_sheets",
    "analysis_output/report",
]
for _d in DIRS:
    os.makedirs(_d, exist_ok=True)

# ── Logging ────────────────────────────────────────────────────────────────
_LOG_PATH = "analysis_output/debug/pipeline.log"

def log(msg: str) -> None:
    ts = time.strftime("%H:%M:%S")
    line = f"[{ts}] {msg}"
    print(line, flush=True)
    with open(_LOG_PATH, "a") as _lf:
        _lf.write(line + "\n")

# ── Validation flags ───────────────────────────────────────────────────────
_validation_flags: list[str] = []

def set_validation_flag(flag: str) -> None:
    if flag not in _validation_flags:
        _validation_flags.append(flag)
        log(f"[FLAG] {flag}")

# ── Wall-clock timing ──────────────────────────────────────────────────────
_step_times: dict[str, float] = {}

def step_start(name: str) -> float:
    t = time.time()
    _step_times[name] = t
    log(f"[STEP START] {name}")
    return t

def step_end(name: str) -> float:
    elapsed = time.time() - _step_times.get(name, time.time())
    log(f"[STEP END] {name} — {elapsed:.1f}s")
    return elapsed

# ── ffprobe helper ─────────────────────────────────────────────────────────
def ffprobe_video(path: str) -> dict:
    """Return stream dict for first video stream via ffprobe. Raises on failure."""
    r = subprocess.run([
        "ffprobe", "-v", "error",
        "-select_streams", "v:0",
        "-show_entries",
        "stream=width,height,nb_frames,r_frame_rate,sample_aspect_ratio,display_aspect_ratio,codec_name",
        "-show_entries", "format=duration",
        "-of", "json", path
    ], capture_output=True, text=True)
    if r.returncode != 0:
        raise RuntimeError(f"[ABORT] ffprobe failed on {path}:\n{r.stderr}")
    data = json.loads(r.stdout)
    streams = data.get("streams", [])
    if not streams:
        raise RuntimeError(f"[ABORT] ffprobe found no video streams in {path}")
    s = streams[0]
    s["_format"] = data.get("format", {})
    return s

# ── Minimum file size guard ────────────────────────────────────────────────
def assert_file_exists(path: str, min_bytes: int = 1000, label: str = "") -> None:
    tag = f" [{label}]" if label else ""
    if not os.path.exists(path):
        raise RuntimeError(f"[ABORT]{tag} Expected file does not exist: {path}")
    size = os.path.getsize(path)
    if size < min_bytes:
        raise RuntimeError(f"[ABORT]{tag} File too small ({size} < {min_bytes} bytes): {path}")
    log(f"[OK]{tag} {path} ({size:,} bytes)")
```

**2.2 — Compute Orbit-Aware Crop Box**

```python
def compute_crop_box(trajectories, tracked_label, ref_label, fw, fh, pad=1.3):
    """
    Compute a padded bounding box that covers all detections of both labels.
    Returns (x_off, y_off, crop_w, crop_h) with even dimensions (libx264 req).
    """
    all_bboxes = []
    for label in [tracked_label, ref_label]:
        for det in trajectories.get(label, []):
            if det.get("bbox"):
                all_bboxes.append(det["bbox"])

    if not all_bboxes:
        log("[ROI] No bboxes found — returning full frame.")
        return (0, 0, fw, fh)

    bboxes = np.array(all_bboxes, dtype=float)
    env_x0, env_y0 = bboxes[:, 0].min(), bboxes[:, 1].min()
    env_x1, env_y1 = bboxes[:, 2].max(), bboxes[:, 3].max()
    env_cx = (env_x0 + env_x1) / 2
    env_cy = (env_y0 + env_y1) / 2

    crop_w = int(min((env_x1 - env_x0) * pad, fw))
    crop_h = int(min((env_y1 - env_y0) * pad, fh))

    crop_w = crop_w if crop_w % 2 == 0 else crop_w - 1
    crop_h = crop_h if crop_h % 2 == 0 else crop_h - 1

    x_off = int(max(0, min(env_cx - crop_w / 2, fw - crop_w)))
    y_off = int(max(0, min(env_cy - crop_h / 2, fh - crop_h)))

    x_off = max(0, min(x_off, fw - crop_w))
    y_off = max(0, min(y_off, fh - crop_h))

    return (x_off, y_off, crop_w, crop_h)

pad      = 1.3
crop_box = compute_crop_box(trajectories_full, tracked_label, ref_label, FRAME_W, FRAME_H, pad)
```

**2.3 — Crop Validation Loop (math only)**

Validate the crop by transforming full-frame bounding boxes into crop-space. If validation fails, widen and retry.

```python
MAX_ITER           = 3
COVERAGE_THRESHOLD = 0.80   # ≥ 80% of detections must land inside crop
MARGIN_THRESHOLD   = 20     # px — bbox must not clip the crop boundary

for iteration in range(1, MAX_ITER + 1):
    x_off, y_off, crop_w, crop_h = crop_box
    tracked_dets = trajectories_full.get(tracked_label, [])

    total_detections = len(tracked_dets)
    if total_detections == 0:
        log("[ROI] No detections for tracked label — falling back to full frame.")
        crop_box = (0, 0, FRAME_W, FRAME_H)
        set_validation_flag("roi_crop_failed_fallback")
        break

    n_in_crop, margins = 0, []
    for d in tracked_dets:
        bx0, by0, bx1, by1 = d["bbox"]
        cx0, cy0 = bx0 - x_off, by0 - y_off
        cx1, cy1 = bx1 - x_off, by1 - y_off
        ccx = (cx0 + cx1) / 2
        ccy = (cy0 + cy1) / 2
        if 0 <= ccx <= crop_w and 0 <= ccy <= crop_h:
            n_in_crop += 1
            m_left   = cx0 if x_off > 0 else 9999.0
            m_top    = cy0 if y_off > 0 else 9999.0
            m_right  = crop_w - cx1 if x_off + crop_w < FRAME_W else 9999.0
            m_bottom = crop_h - cy1 if y_off + crop_h < FRAME_H else 9999.0
            margins += [m_left, m_top, m_right, m_bottom]

    coverage   = n_in_crop / total_detections
    min_margin = float(np.min(margins)) if margins else 0.0

    log(f"[ROI iter {iteration}] coverage={coverage:.2f}  min_margin={min_margin:.1f}px  crop={crop_box}")

    if coverage >= COVERAGE_THRESHOLD and min_margin >= MARGIN_THRESHOLD:
        log(f"[ROI] Accepted at iteration {iteration}.")
        break

    if coverage < COVERAGE_THRESHOLD:
        log(f"[ROI] Low coverage ({coverage:.2f} < {COVERAGE_THRESHOLD}). Widening by 15%.")
    else:
        log(f"[ROI] Margin too small ({min_margin:.1f}px < {MARGIN_THRESHOLD}px). Widening by 15%.")

    pad *= 1.15
    crop_box = compute_crop_box(trajectories_full, tracked_label, ref_label, FRAME_W, FRAME_H, pad)

    if iteration == MAX_ITER:
        set_validation_flag("roi_crop_failed_fallback")
        log("[ROI] All iterations exhausted — falling back to full frame.")
        crop_box = (0, 0, FRAME_W, FRAME_H)

x_off, y_off, crop_w, crop_h = crop_box
use_full_frame = (crop_box == (0, 0, FRAME_W, FRAME_H))
```

**2.4 — Transform Trajectories & Crop Video**

```python
def transform_to_crop_space(trajectories_full, x_off, y_off):
    cropped = {}
    for label, dets in trajectories_full.items():
        cropped[label] = []
        for d in dets:
            bx0, by0, bx1, by1 = d["bbox"]
            new_det = {
                "frame": d["frame"],
                "cx":    d["cx"] - x_off,
                "cy":    d["cy"] - y_off,
                "bbox":  [bx0 - x_off, by0 - y_off, bx1 - x_off, by1 - y_off],
            }
            if "obox" in d:
                new_det["obox"] = [[p[0] - x_off, p[1] - y_off] for p in d["obox"]]
            cropped[label].append(new_det)
    return cropped

MIN_VIDEO_BYTES = 50_000

if use_full_frame:
    trajectories       = trajectories_full
    final_cropped_path = VIDEO_PATH
    log(f"[ROI] Full-frame path — no ffmpeg crop. Using: {VIDEO_PATH}")
    assert_file_exists(VIDEO_PATH, min_bytes=MIN_VIDEO_BYTES, label="source_video")
else:
    trajectories       = transform_to_crop_space(trajectories_full, x_off, y_off)
    final_cropped_path = "analysis_output/roi/cropped.mp4"

    log(f"[ROI] Cropping {FRAME_W}x{FRAME_H} → {crop_w}x{crop_h} @ offset ({x_off},{y_off})")

    ffmpeg_crop = subprocess.run([
        "ffmpeg", "-y", "-i", VIDEO_PATH,
        "-vf",    f"crop={crop_w}:{crop_h}:{x_off}:{y_off}",
        "-c:v",   "libx264", "-crf", "18", "-preset", "fast",
        final_cropped_path
    ], capture_output=True, text=True)

    if ffmpeg_crop.returncode != 0:
        raise RuntimeError(f"[ABORT] ffmpeg crop failed:\n{ffmpeg_crop.stderr}")

    assert_file_exists(final_cropped_path, min_bytes=MIN_VIDEO_BYTES, label="cropped.mp4")

    crop_stream = ffprobe_video(final_cropped_path)
    actual_w, actual_h = int(crop_stream["width"]), int(crop_stream["height"])

    if actual_w != crop_w or actual_h != crop_h:
        raise RuntimeError(f"[ABORT] Cropped video dimensions mismatch: expected {crop_w}x{crop_h}, got {actual_w}x{actual_h}.")

    actual_nb = int(crop_stream.get("nb_frames", 0))
    if actual_nb < 1:
        raise RuntimeError(f"[ABORT] Cropped video reports 0 frames: {final_cropped_path}")

    log(f"[ROI] Cropped video verified: {actual_w}x{actual_h}, {actual_nb} frames — {final_cropped_path}")
```

### Coordinate Mapping Helpers

```python
def cropped_to_original(cx, cy, crop_meta):
    """Map a point from cropped-video space back to original-frame space."""
    return cx + crop_meta["x_off"], cy + crop_meta["y_off"]

def original_to_cropped(ox, oy, crop_meta):
    """Map a point from original-frame space to cropped-video space."""
    return ox - crop_meta["x_off"], oy - crop_meta["y_off"]

### Step 7 — Active Interval Detection

```python
import scipy.ndimage
step_start("step7")

dx_full = x_full - cx_px
dy_full = y_full - cy_px
r_coarse = np.sqrt(dx_full**2 + dy_full**2)
t_s      = np.arange(n_raw_frames) / FPS

theta_coarse = np.arctan2(dy_full, dx_full)

def nan_safe_unwrap(arr):
    result = np.full_like(arr, np.nan)
    valid  = ~np.isnan(arr)
    labeled, n_segs = scipy.ndimage.label(valid)
    for i in range(1, n_segs + 1):
        mask = labeled == i
        result[mask] = np.unwrap(arr[mask])
    return result

theta_unwrapped_coarse = nan_safe_unwrap(theta_coarse)

def nan_aware_gradient(arr, t):
    result = np.full_like(arr, np.nan)
    valid  = ~np.isnan(arr)
    labeled, n_segs = scipy.ndimage.label(valid)
    for i in range(1, n_segs + 1):
        mask = labeled == i
        result[mask] = np.gradient(arr[mask], t[mask])
    return result

omega_raw   = nan_aware_gradient(theta_unwrapped_coarse, t_s)
filter_size = max(5, int(FPS // 10))
omega_smooth = scipy.ndimage.median_filter(omega_raw, size=filter_size, mode='nearest')

omega_threshold_pct = 0.10 if duration_s >= 10 else 0.20
omega_max           = np.nanmax(np.abs(omega_smooth))
omega_threshold     = omega_threshold_pct * omega_max

MIN_ACTIVE_DURATION_S = max(0.5, 1.0 / omega_threshold_pct / 10)
MIN_ACTIVE_FRAMES     = max(1, int(MIN_ACTIVE_DURATION_S * FPS))

active_raw = np.abs(omega_smooth) > omega_threshold

labeled_active, n_bursts = scipy.ndimage.label(active_raw)
active_mask = np.zeros(n_raw_frames, dtype=bool)
for i in range(1, n_bursts + 1):
    burst = labeled_active == i
    if burst.sum() >= MIN_ACTIVE_FRAMES:
        active_mask |= burst

np.save("analysis_output/data/active_mask.npy", active_mask)
active_duration_s = float(active_mask.sum()) / FPS
log(f"[Step 7] active_duration={active_duration_s:.2f}s  omega_threshold={omega_threshold:.4f} rad/s")

step_end("step7")

savgol_window    = max(11, 2 * (int(FPS) // 6) + 1)
if savgol_window % 2 == 0:
    savgol_window += 1
savgol_polyorder = 3

def savgol_nan_safe(signal: np.ndarray, window: int, polyorder: int) -> np.ndarray:
    result  = np.full_like(signal, np.nan, dtype=float)
    valid   = ~np.isnan(signal)
    labeled, n_segs = scipy.ndimage.label(valid)
    for i in range(1, n_segs + 1):
        seg_mask = labeled == i
        seg      = signal[seg_mask]
        n        = len(seg)
        if n >= window:
            result[seg_mask] = savgol_filter(seg, window, polyorder)
        elif n >= polyorder + 1:
            w = n if n % 2 == 1 else n - 1
            w = max(w, polyorder + 1)
            if w % 2 == 0: w -= 1
            if w > polyorder:
                result[seg_mask] = savgol_filter(seg, w, polyorder)
    return result

r_m_smooth = savgol_nan_safe(r_m, savgol_window, savgol_polyorder)
theta_smooth = savgol_nan_safe(theta_unwrapped, savgol_window, savgol_polyorder)

**5.8 — Phase Detection**

Compute on `ω[active_mask]` only.
Smooth ω for phase detection with additional `median_filter(size=int(fps * 0.5))`
before differencing — do not modify `ω` used for kinematics.

```python
dω_dt              = NaN-aware gradient of smoothed ω w.r.t. t_s
increase_threshold =  0.10 * nanmax(abs(dω_dt))
decrease_threshold = -0.10 * nanmax(abs(dω_dt))
```

Phases:
- `INCREASE` : `dω_dt > increase_threshold`  sustained ≥ 0.5 s
- `DECREASE` : `dω_dt < decrease_threshold`  sustained ≥ 0.5 s
- `STABLE`   : otherwise within active mask

**stable_mean_omega — linear regression on θ(t):**

```python
stable_segments = [intervals where phase == STABLE]

if len(stable_segments) == 0 or sum(stable_mask) < fps * 0.5:
    set_validation_flag("no_stable_phase_detected")
    stable_mean_omega    = float(np.nanmedian(np.abs(ω_active)))
    stable_mean_ac       = mean_ac
    stable_omega_r2      = float("nan")
    stable_omega_std_err = float("nan")
    log("[PHASE] No stable phase detected — using median ω as fallback")
else:
    slopes, weights, r2_values, std_errs = [], [], [], []
    for interval in stable_segments:
        t_seg = t_s[interval & ~isnan(θ_unwrapped)]
        θ_seg = θ_unwrapped[interval & ~isnan(θ_unwrapped)]
        if len(t_seg) < 2:
            continue
        slope, _, r2, _, std_err = scipy.stats.linregress(t_seg, θ_seg)
        if r2 < 0.99:
            set_validation_flag("unstable_phase_linearity")
        slopes.append(slope)
        weights.append(len(t_seg))
        r2_values.append(r2)
        std_errs.append(std_err)

    if len(slopes) == 0:
        set_validation_flag("no_stable_phase_detected")
        stable_mean_omega    = float(np.nanmedian(np.abs(ω_active)))
        stable_mean_ac       = mean_ac
        stable_omega_r2      = float("nan")
        stable_omega_std_err = float("nan")
    else:
        weights              = np.array(weights)
        stable_mean_omega    = float(np.average(slopes, weights=weights))
        stable_mean_ac       = nanmean(ac_m_s2 during STABLE phases)
        stable_omega_r2      = float(np.average(r2_values, weights=weights))
        stable_omega_std_err = float(np.average(std_errs,  weights=weights))

increase_start_omega = ω at start of first INCREASE phase  (NaN if none)
increase_end_omega   = ω at end   of last  INCREASE phase  (NaN if none)
decrease_end_omega   = ω at end   of last  DECREASE phase  (NaN if none)
