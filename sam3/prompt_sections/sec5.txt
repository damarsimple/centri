## PARALLEL WAVE — Three Subagents

Spawn all three simultaneously once `stats.json` is written.

Pass each subagent:
1. Its subagent definition file (as system prompt)
2. The stats dict values injected directly as context
3. File paths only for large data (cropped video, CSV, cache JSON)

Note for all subagents: pixel coordinates in all data files are in
**cropped-video space**. The `roi_crop` block in `stats.json` contains the
offset to the original frame if needed.

### Subagent A — Video Annotation
- Definition: `.pi/agents/video-annotation-subagent.md`
- Input video: `cropped_video_path` from stats.json (the cropped video)
- Output: `analysis_output/video_annotation/annotated_video.mp4`
- Annotates the cropped video — the tighter frame improves annotation clarity.
- Separate deliverable — not embedded in LaTeX.
- Does not block LaTeX compilation.

### Subagent B — Figure Generation
- Definition: `.pi/agents/figures-gen-subagent.md`
- Outputs: all plots in `analysis_output/plots/`
- **LaTeX compilation waits for this subagent.**

### Subagent C — Question Generation
- Definition: `.pi/agents/question-gen-subagent.md`
- Output: `analysis_output/data/questions.json`
- **LaTeX compilation waits for this subagent.**
- Needs only `stats.json` — no dependency on figures.

## GATED PHASE — LaTeX Report

Begins only after **both** of these exist:
- `analysis_output/plots/summary_panel.png` (Subagent B complete)
- `analysis_output/data/questions.json` (Subagent C complete)

Must use LaTeX skills.

**9.1 — Macros** — write into both `.tex` files:
```latex
\newcommand{\MeanR}{\SI{<mean_r_m:.3f>}{m}}
\newcommand{\MeanOmega}{\SI{<stable_mean_omega:.2f>}{rad/s}}
\newcommand{\MeanAc}{\SI{<stable_mean_ac:.2f>}{m/s^2}}
\newcommand{\MaxAc}{\SI{<max_ac:.2f>}{m/s^2}}
\newcommand{\MeanV}{\SI{<mean_v:.2f>}{m/s}}
\newcommand{\Period}{\SI{<period_s:.2f>}{s}}
\newcommand{\Frequency}{\SI{<frequency_hz:.2f>}{Hz}}
\newcommand{\OmegaIncStart}{\SI{<increase_start_omega:.2f>}{rad/s}}
\newcommand{\OmegaIncEnd}{\SI{<increase_end_omega:.2f>}{rad/s}}
\newcommand{\ObjectName}{<object_name>}
```

**9.2 — Load questions** from `analysis_output/data/questions.json` (generated by Subagent C — do not regenerate here).

**9.3–9.4 — Generate** `student_edition.tex` and `teacher_key.tex` per original pipeline conventions.

**9.5 — Compile both PDFs in parallel:**
Spawn two pdflatex processes simultaneously.

Outputs:
- `analysis_output/report/student_edition.pdf`
- `analysis_output/report/teacher_key.pdf`

## FINAL STEP — report.md

Write only after all subagents and LaTeX compilation are complete.

Include:
1. Wall-clock timings per step (including subagent durations)
2. Cache status (HIT/MISS; API response time if MISS)
3. ROI crop summary: iterations attempted, final crop box, coverage, margin, fallback triggered (yes/no), note: validation was math-based (no re-tracking)
4. Calibration: `px_per_m`, `(cx, cy)`, center source, coordinate space note
5. Summary statistics table
6. Phase boundaries from `phases.json`
7. Validation flags raised (if any)
8. Question bank summary (count, Bloom's distribution, regenerations)
9. Subagent status: completed / failed / skipped (A, B, C)
10. Full output file manifest — all PDFs, videos, plots, CSVs, JSONs
