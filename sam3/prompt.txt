### Step 1.5 — ROI Detection & Crop (1 API Call, Cached)

> **Purpose:** Crop the video to the region of interest before sending to the
> tracking API. A tight, object-centred crop eliminates background clutter that
> degrades SAM 2 mask propagation. All pixel coordinates downstream are in
> **cropped-video space**.
>
> **This step makes AT MOST 1 HTTP API call. If `api_cache.json` exists
> from a previous run, the API is NOT called at all (cache HIT).**
> Crop-space trajectories are produced by subtracting the crop offset
> from full-frame coordinates — NOT by calling the API again.
>
> **Tracking is done by the remote server via `requests.post()`. Do NOT
> import or run any tracking model locally.**

**Algorithm overview:**
1. Check for cached API results. If cache miss, call the tracking API ONCE
   on the original video.
2. Compute an orbit-aware crop box from the returned trajectories.
3. Validate the crop via coordinate transform (math only, no API).
   If it fails, widen and retry (max 3 iterations, all instant math).
4. Transform trajectories to crop space by subtracting the offset.
5. Crop the video with ffmpeg (for downstream visual use only).
6. Store crop metadata. All downstream steps use the cropped video.

**1.5.2 — Compute Orbit-Aware Crop Box**

```python
def compute_crop_box(trajectories, tracked_label, ref_label, fw, fh, pad=1.3):
    all_bboxes = []
    for label in [tracked_label, ref_label]:
        for det in trajectories.get(label, []):
            all_bboxes.append(det["bbox"])
    if not all_bboxes:
        return (0, 0, fw, fh)
    bboxes = np.array(all_bboxes)
    env_x0, env_y0 = bboxes[:, 0].min(), bboxes[:, 1].min()
    env_x1, env_y1 = bboxes[:, 2].max(), bboxes[:, 3].max()
    env_cx = (env_x0 + env_x1) / 2
    env_cy = (env_y0 + env_y1) / 2
    crop_w = int(min((env_x1 - env_x0) * pad, fw))
    crop_h = int(min((env_y1 - env_y0) * pad, fh))
    x_off  = int(max(0, min(env_cx - crop_w / 2, fw - crop_w)))
    y_off  = int(max(0, min(env_cy - crop_h / 2, fh - crop_h)))
    return (x_off, y_off, crop_w, crop_h)

pad = 1.3
crop_box = compute_crop_box(trajectories_full, tracked_label, ref_label,
                            FRAME_W, FRAME_H, pad)
```

**1.5.3 — Crop Validation Loop (math only, NO API calls)**

Validate the crop by transforming full-frame bounding boxes into crop-space
via coordinate subtraction. If validation fails, widen and retry. All
iterations are instant math — no re-tracking.

```python
MAX_ITER           = 3
COVERAGE_THRESHOLD = 0.80   # ≥ 80 % of frames must contain the tracked object
MARGIN_THRESHOLD   = 20     # px — bbox must not clip the crop boundary

for iteration in range(1, MAX_ITER + 1):
    x_off, y_off, crop_w, crop_h = crop_box
    tracked_dets = trajectories_full.get(tracked_label, [])
    n_in_crop, margins = 0, []

    for d in tracked_dets:
        bx0, by0, bx1, by1 = d["bbox"]
        # Transform to crop space by subtracting offset
        cx0, cy0 = bx0 - x_off, by0 - y_off
        cx1, cy1 = bx1 - x_off, by1 - y_off
        ccx, ccy = (cx0 + cx1) / 2, (cy0 + cy1) / 2
        if 0 <= ccx <= crop_w and 0 <= ccy <= crop_h:
            n_in_crop += 1
            margins += [cx0, cy0, crop_w - cx1, crop_h - cy1]

    total_frames = NB_FRAMES
    coverage     = n_in_crop / max(total_frames, 1)
    min_margin   = float(np.min(margins)) if margins else 0.0

    log(f"[ROI iter {iteration}] coverage={coverage:.2f} "
        f"min_margin={min_margin:.1f}px  crop={crop_box}")

    # --- Exit if valid ---
    if coverage >= COVERAGE_THRESHOLD and min_margin >= MARGIN_THRESHOLD:
        log(f"[ROI] Accepted at iteration {iteration}.")
        break

    # --- Diagnose and widen ---
    if coverage < COVERAGE_THRESHOLD:
        log(f"[ROI] Low coverage ({coverage:.2f} < {COVERAGE_THRESHOLD}). "
            "Widening crop uniformly by 15 %.")
    elif min_margin < MARGIN_THRESHOLD:
        log(f"[ROI] Object clips crop boundary (margin={min_margin:.1f}px). "
            "Widening crop uniformly by 15 %.")
    pad *= 1.15

    crop_box = compute_crop_box(trajectories_full, tracked_label, ref_label,
                                FRAME_W, FRAME_H, pad)

    if iteration == MAX_ITER:
        set_validation_flag("roi_crop_failed_fallback")
        log("[ROI] All iterations failed. Falling back to full frame.")
        crop_box = (0, 0, FRAME_W, FRAME_H)
        break

x_off, y_off, crop_w, crop_h = crop_box
use_full_frame = (crop_box == (0, 0, FRAME_W, FRAME_H))
```

**1.5.4 — Transform Trajectories to Crop Space & Crop Video**

Transform all trajectory coordinates to cropped-video space by subtracting
the crop offset. This is pure arithmetic — NO API call.

```python
def transform_to_crop_space(trajectories_full, x_off, y_off):
    """Subtract crop offset from all coordinates. No API call."""
    cropped = {}
    for label, dets in trajectories_full.items():
        cropped[label] = []
        for d in dets:
            bx0, by0, bx1, by1 = d["bbox"]
            new_det = {
                "frame": d["frame"],
                "cx": d["cx"] - x_off,
                "cy": d["cy"] - y_off,
                "bbox": [bx0 - x_off, by0 - y_off, bx1 - x_off, by1 - y_off],
            }
            if "obox" in d:
                new_det["obox"] = [[p[0] - x_off, p[1] - y_off] for p in d["obox"]]
            cropped[label].append(new_det)
    return cropped

if use_full_frame:
    trajectories       = trajectories_full
    final_cropped_path = VIDEO_PATH
else:
    trajectories       = transform_to_crop_space(trajectories_full, x_off, y_off)
    final_cropped_path = "analysis_output/roi/cropped.mp4"
    os.makedirs("analysis_output/roi", exist_ok=True)
    subprocess.run([
        "ffmpeg", "-y", "-i", VIDEO_PATH,
        "-vf", f"crop={crop_w}:{crop_h}:{x_off}:{y_off}",
        "-c:v", "libx264", "-crf", "18", "-preset", "fast",
        final_cropped_path
    ], check=True)
```

### Coordinate Mapping Helper

```python
def cropped_to_original(cx, cy, crop_meta):
    """Map a point from cropped-video space back to original-frame space."""
    return cx + crop_meta["x_off"], cy + crop_meta["y_off"]

def original_to_cropped(ox, oy, crop_meta):
    """Map a point from original-frame space to cropped-video space."""
    return ox - crop_meta["x_off"], oy - crop_meta["y_off"]
```

**Coordinate Validation (required — do not skip):**

**IMPORTANT RULE ON ROTATION**: The tracking API natively processes and returns coordinates in **Display Space** (e.g., 1080x1920 for a portrait video). Additionally, FFmpeg automatically applies rotation before filters, meaning the `-vf crop` filter also operates in **Display Space**. 
**THEREFORE, YOU MUST NEVER TRANSFORM COORDINATES TO STORED SPACE.** Use the API coordinates exactly as they are.

Validate coordinate axes against the actual cropped frame. 
**CRITICAL**: Do NOT use `fps=1` to extract validation frames. `fps=1` extracts frames at t=0.5s, 1.5s, etc., causing severe temporal misalignment when compared against frame integer indices. Instead, use the `select` filter to extract exactly `int(FPS)` frame.

### Step 2.5 — Trajectory Cleaning (Circular Prior)

> Requires `cx_calibration`, `cy_calibration` from Step 2.8.
> All coordinates are in cropped-video space.

The tracked object moves in circular motion. Use this geometric constraint to
reject bad detections before kinematics.

**1. RANSAC circle fit on tracked object trajectory**
- Input: raw (x, y) from Step 2, valid frames only
- Fixed seed: `np.random.RandomState(seed=42)` — required for reproducibility
- Inlier threshold: 5.0 px
- Minimum iterations: 1000
- Refine final fit with least squares on all inliers
- Outputs: `cx_fit`, `cy_fit`, `r_fit_px`, `inlier_mask`

**RANSAC fallback (required):**

```python
MIN_INLIERS = max(20, int(0.15 * n_valid_frames))

if n_inliers < MIN_INLIERS:
    set_validation_flag("ransac_insufficient_inliers")
    cx_fit   = cx_calibration
    cy_fit   = cy_calibration
    r_fit_px = float(np.nanmedian(
        np.sqrt((x_valid - cx_calibration)**2 + (y_valid - cy_calibration)**2)
    ))
    inlier_mask = np.ones(len(x_valid), dtype=bool)
    log(f"[RANSAC FALLBACK] Insufficient inliers ({n_inliers} < {MIN_INLIERS}). "
        f"Using median radius: {r_fit_px:.1f} px")
```

**2. Outlier rejection**
```python
r_per_frame = sqrt((x - cx_calibration)² + (y - cy_calibration)²)
sigma_r     = nanstd(r_per_frame[inlier_mask])
outlier     = |r_per_frame - nanmedian(r_per_frame)| > 2.5 * sigma_r
# Set outlier frames → NaN. Never interpolate.
```

**3. Cross-validate and select rotation center**
```python
center_drift_px = sqrt((cx_fit - cx_calibration)² + (cy_fit - cy_calibration)²)

if center_drift_px <= 10:
    cx_active, cy_active = cx_calibration, cy_calibration
    center_source = "tire_hub_median"

    cx_active, cy_active = cx_fit, cy_fit
    center_source = "ransac_fit"

```

### Step 3 — Calibration

**Rotation center**

Reuse `cx_calibration`, `cy_calibration` computed in Step 2.8.
Do not recompute. Coordinates are in cropped-video space.

**Pixel diameter**

For every valid reference object detection frame:
```python
width_px  = bbox[2] - bbox[0]
height_px = bbox[3] - bbox[1]

width_px_median  = np.median(width_px_per_frame)
height_px_median = np.median(height_px_per_frame)
diameter_px      = (width_px_median + height_px_median) / 2.0

if abs(width_px_median - height_px_median) / diameter_px > 0.15:
    set_validation_flag("bbox_aspect_suspicious")
    log(f"[WARN] width_px_median={width_px_median:.1f} "
        f"height_px_median={height_px_median:.1f} differ > 15%")
```

FORBIDDEN — any of these is a pipeline error, do not proceed:
- Using bbox diagonal `sqrt(w²+h²)`
- Using width or height alone, not both
- Using any radius (half of any dimension)
- Using the tracked object's orbit radius to derive scale

**Physical size**

Estimate the OUTER diameter of the reference object including all outer layers
in meters, using world knowledge of the label. For bicycle tires: outer
diameter includes rim + mounted tire rubber, not rim alone, not inner
diameter, not a vehicle wheel. Document the estimate and one-sentence
reasoning in `calibration_log.txt`. Set validation_flag:
`"physical_size_estimated"`.

**Scale**
```python
px_per_m = diameter_px / physical_size_m
```

**NaN-safe Savgol — use exactly this implementation:**

```python
import scipy.ndimage
from scipy.signal import savgol_filter

def savgol_nan_safe(signal: np.ndarray, window: int, polyorder: int) -> np.ndarray:
    result = np.full_like(signal, np.nan, dtype=float)
    valid  = ~np.isnan(signal)
    labeled, n_segs = scipy.ndimage.label(valid)
    for i in range(1, n_segs + 1):
        seg_mask = labeled == i
        seg      = signal[seg_mask]
        n        = len(seg)
        if n >= window:
            result[seg_mask] = savgol_filter(seg, window, polyorder)
        elif n >= polyorder + 1:
            w = n if n % 2 == 1 else n - 1
            w = max(w, polyorder + 1)
            if w % 2 == 0:
                w -= 1
            if w > polyorder:
                result[seg_mask] = savgol_filter(seg, w, polyorder)
    return result

r_m_smooth = savgol_nan_safe(r_m,          savgol_window, savgol_polyorder)
θ_smooth   = savgol_nan_safe(θ_unwrapped,  savgol_window, savgol_polyorder)
```

Do not interpolate across NaN gaps. Output retains NaN at all gap positions.

**5.8 — Phase Detection**

Compute on `ω[active_mask]` only.
Smooth ω for phase detection with additional `median_filter(size=int(fps * 0.5))`
before differencing — do not modify `ω` used for kinematics.

```python
dω_dt              = NaN-aware gradient of smoothed ω w.r.t. t_s
increase_threshold =  0.10 * nanmax(abs(dω_dt))
decrease_threshold = -0.10 * nanmax(abs(dω_dt))
```

Phases:
- `INCREASE` : `dω_dt > increase_threshold`  sustained ≥ 0.5 s
- `DECREASE` : `dω_dt < decrease_threshold`  sustained ≥ 0.5 s
- `STABLE`   : otherwise within active mask

**stable_mean_omega — linear regression on θ(t):**

```python
stable_segments = [intervals where phase == STABLE]

if len(stable_segments) == 0 or sum(stable_mask) < fps * 0.5:
    set_validation_flag("no_stable_phase_detected")
    stable_mean_omega    = float(np.nanmedian(np.abs(ω_active)))
    stable_mean_ac       = mean_ac
    stable_omega_r2      = float("nan")
    stable_omega_std_err = float("nan")
    log("[PHASE] No stable phase detected — using median ω as fallback")
else:
    slopes, weights, r2_values, std_errs = [], [], [], []
    for interval in stable_segments:
        t_seg = t_s[interval & ~isnan(θ_unwrapped)]
        θ_seg = θ_unwrapped[interval & ~isnan(θ_unwrapped)]
        if len(t_seg) < 2:
            continue
        slope, _, r2, _, std_err = scipy.stats.linregress(t_seg, θ_seg)
        if r2 < 0.99:
            set_validation_flag("unstable_phase_linearity")
        slopes.append(slope)
        weights.append(len(t_seg))
        r2_values.append(r2)
        std_errs.append(std_err)

    if len(slopes) == 0:
        set_validation_flag("no_stable_phase_detected")
        stable_mean_omega    = float(np.nanmedian(np.abs(ω_active)))
        stable_mean_ac       = mean_ac
        stable_omega_r2      = float("nan")
        stable_omega_std_err = float("nan")
    else:
        weights              = np.array(weights)
        stable_mean_omega    = float(np.average(slopes, weights=weights))
        stable_mean_ac       = nanmean(ac_m_s2 during STABLE phases)
        stable_omega_r2      = float(np.average(r2_values, weights=weights))
        stable_omega_std_err = float(np.average(std_errs,  weights=weights))

increase_start_omega = ω at start of first INCREASE phase  (NaN if none)
increase_end_omega   = ω at end   of last  INCREASE phase  (NaN if none)
decrease_end_omega   = ω at end   of last  DECREASE phase  (NaN if none)
```
